# Specification-driven development

1. Express observable requirements as acceptance criteria.
2. Identify edge cases, non-functional requirements, and dependencies.
3. Produce an implementation plan before changing product code.
4. Implement in small verifiable steps.
5. Map every requirement to code and test evidence before declaring completion.
