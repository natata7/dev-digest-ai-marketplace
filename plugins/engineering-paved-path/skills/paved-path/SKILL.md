# Engineering paved path

1. Inspect the repository conventions and existing patterns before editing.
2. Identify the smallest complete set of files and interfaces involved.
3. Make a focused change that preserves existing behavior outside the request.
4. Validate with the narrowest relevant test, type check, or build.
5. Report changed files, validation evidence, and any remaining risks.
