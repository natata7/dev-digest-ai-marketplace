# Engineering Paved Path

Reusable engineering workflows and delivery guardrails for Claude Code. This is the shared foundation used by the other marketplace workflows.

## Components

- `skills/paved-path/SKILL.md` — guides implementation through discovery, focused changes, and validation.

## Composition

Research Tools, Architecture Review, and SDD Engineering remain independently installable but may reuse these conventions. The relationship is documented composition, not an automatic install-time dependency.

## Install

```text
/plugin marketplace add natata7/dev-digest-ai-marketplace
/plugin install engineering-paved-path@dev-digest-ai-marketplace
```
