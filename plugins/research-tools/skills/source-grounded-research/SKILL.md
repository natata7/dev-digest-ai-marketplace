# Source-grounded research

1. Prefer primary documentation and source code over summaries.
2. Record the exact URL or file path for each material claim.
3. Separate verified facts, observed examples, and recommendations.
4. Note dates and version assumptions when behavior may change.
5. End with actionable conclusions and unresolved questions.
