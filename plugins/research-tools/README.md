# Research Tools

Workflows for finding, checking, and communicating evidence from repositories and the web.

## When to use it

Use this plugin before specification work when requirements depend on current repository behavior, external documentation, or competing implementation options.

## Components

- `agents/researcher.md` — investigates a bounded question and returns evidence-backed findings.
- `skills/source-grounded-research/SKILL.md` — keeps research traceable to sources and separates facts from recommendations.

## Composition

Research Tools is independently installable. Its findings can be handed to SDD Engineering or Architecture Review, and it follows the shared discovery and validation conventions from Engineering Paved Path.

## Install

```text
/plugin marketplace add natata7/dev-digest-ai-marketplace
/plugin install research-tools@dev-digest-ai-marketplace
```
